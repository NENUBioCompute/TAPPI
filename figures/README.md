## 🔧 Requirements

Before using this feature, please make sure the following Python packages are installed:

- `openpyxl`
- `ptitprince`
- `seaborn`
- `gseapy`

### Install via pip

```bash
pip install openpyxl ptitprince seaborn gseapy
```
